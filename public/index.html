Über Orrery

Orrery ist ein generatives Licht- und Klang-Spielzeug. Setze leuchtende Körper in den Nachthimmel, lass sie sich anziehen, hör ihnen beim Klingen zu, oder forme aus ihnen Sternbilder.

Gebaut mit nichts als HTML, CSS und JavaScript — keine Engine, kein Build-Schritt. Musik und Klang entstehen live über die Web Audio API.
